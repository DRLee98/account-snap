## 화면 구성

```
[‹]         결과          [☆]
┌──────── 사진 160 ─────────┐   은행·계좌번호·예금주 자리에 색 상자
│  [크게 보기]    [다시 칠하기] │
└───────────────────────────┘
(계좌 여러 개면) 사진에서 계좌 2개를 찾았어요 · 다른 계좌로 바꾸기 ›
┌ ● 은행    국민은행        › ┐  초록 점 — 누르면 은행 목록 시트
│ ● 계좌번호                   │  파란 점
│   110123-45-678901   [복사] │
│   ✓ 국민은행 계좌번호 형식(14자리)과 맞아요
│ ● 예금주  홍길동          ✎ │  보라 점
│   별칭    (선택) …        ✎ │
└───────────────────────────┘
사진의 같은 색 상자에서 읽은 값이에요 · 눌러서 고칠 수 있어요
[광고 320×100]
━━━━━━━━━━ 아래 고정 ━━━━━━━━━━
[  토스로 송금하기  ]
주거래 은행 · 토스 변경 ›
```

- 헤더: 뒤로 가기(카메라로) + 즐겨찾기 별(`FavoriteHeaderButton`). 계좌는 인식 직후 이미 저장돼 있어 완료 버튼이 없다.
  이전엔 `headerBackVisible: false`로 뒤로 가기를 막고 '완료'로만 나갔다.
- 저장 알림: 초록 캡슐 토스트 `type: 'saved'` (`src/components/toastConfig.tsx`) — 헤더 아래로 내려왔다 2.5초 뒤 사라짐.
  문구 "목록에 저장하고 계좌번호를 복사했어요". 인식 직후 복사 알림(크롭 화면)은 이 알림으로 합쳤다.
- 키보드가 올라오면 아래 송금 버튼은 잠시 숨긴다.

## 사진 위 색 상자 (개선 2)

- `recognizeAccount()`가 OCR 글자 박스로 계좌마다 `regions`(은행·계좌번호·예금주 자리)를 붙이고 좌표 단위(`regionUnit`)를 돌려준다.
  - CLOVA: 픽셀 / iOS Vision: 0~1 비율(네이티브에서 왼쪽 위 원점으로 변환) / Android ML Kit: 픽셀
- `locateAccount()` (`src/services/ocr/regions.ts`)
  - 계좌번호: 읽기 순서로 이어 붙인 숫자에 계좌번호가 들어가는 가장 짧은 연속 박스 묶음 (여러 박스로 나뉜 번호도 찾음)
  - 은행: 사진 글자에서 은행을 찾았을 때만, 그 은행 별칭이 든 박스
  - 예금주: 이름이 든 박스
- 결과 화면은 사진을 `contain`으로 놓고, 영역을 비율로 바꿔 실제 그려진 자리에 상자를 얹는다 (`AccountPhoto`).
- 좌표는 화면 이동 파라미터로만 넘기고 저장하지 않는다 (목록에서 다시 열 땐 상자 없음).

## 필요할 때만 묻기 (개선 3)

### 계좌가 여러 개
1. **고르기**: 사진 → "사진에서 계좌가 N개 보여요" 안내 → 계좌 카드(›). 송금 버튼은 비활성, 설명 "보낼 계좌를 골라 주세요".
2. **고른 뒤**: 확인 카드. 고른 계좌로 저장을 바꾸고 계좌번호를 복사, 저장 알림. 카드 위 "다른 계좌로 바꾸기"로 1로 돌아간다.
- 저장 시점은 그대로: 들어올 때 첫 계좌를 저장해 두고, 고르면 바꾼다. 고르지 않고 나가도 데이터가 사라지지 않는다.

### 은행을 사진에서 못 찾음
- 파서가 계좌번호 앞자리로 은행을 추정하면 `bankInferred: true`.
- 은행 점은 주황 테두리, 은행 이름은 주황색, 아래 11px 안내 두 줄
  "사진에 은행이 없어 계좌번호로 추정했어요. / 다른 은행이면 눌러서 바꿔 주세요".
- 고치지 않고 송금하면 추정 은행으로 넘긴다 (인식 직후 추정 은행으로 저장돼 있음).
- 추정도 못 하면 "선택해 주세요" + "사진에서 은행을 찾지 못했어요. / 고르면 송금 앱에 계좌까지 채워져요",
  자동입력 앱(토스·카카오페이)이면 송금 버튼 설명도 "은행을 고르면 계좌까지 채워진 화면이 열려요".
- 은행을 고르면 주황 표시가 사라지고 형식 확인 표시가 붙는다. 추정 상태에서 계좌번호를 고치면 바뀐 번호로 다시 추정.

### 은행 형식 확인
- 은행을 사진에서 찾았거나 직접 골랐을 때만: `matchesBankFormat()` 결과로
  "✓ ○○ 계좌번호 형식(N자리)과 맞아요" 또는 "○○ 계좌번호 형식과 달라요. 번호를 확인해 주세요".
- 평생계좌(전화번호 형태)와 자릿수 정보가 없는 은행은 표시하지 않는다.
