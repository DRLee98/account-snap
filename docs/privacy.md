# 스냅넘버 개인정보처리방침

최종 업데이트: 2026-10-20

## 1. 수집하는 정보

스냅넘버는 사용자의 계좌 정보를 외부 서버에 저장하지 않습니다.
모든 계좌 정보(은행명, 계좌번호, 라벨)는 사용자 기기 내 로컬 저장소(MMKV)에만 저장됩니다.

### 1-1. 클립보드

앱을 열거나 다시 활성화할 때, 클립보드에 계좌번호 형식의 텍스트가 있는지 기기 안에서
확인합니다. 카카오톡 등으로 받은 계좌번호를 사진 촬영 없이 저장할 수 있게 하기 위한
기능입니다.

- 확인은 기기 내에서만 이루어지며, 클립보드 내용은 외부로 전송되지 않습니다.
- 계좌번호로 보이는 텍스트가 있으면 저장 여부를 묻고, 사용자가 **저장**을 선택한 경우에만
  로컬 저장소에 저장됩니다. **무시**를 선택하면 저장하지 않으며 같은 번호로 다시 묻지 않습니다.
- 계좌번호 형식이 아닌 클립보드 내용은 사용하지 않고 즉시 버립니다.
- iOS에서는 클립보드를 읽을 때 시스템이 "스냅넘버에서 붙여넣음" 알림을 표시할 수 있습니다.
  이는 iOS의 기본 동작입니다.

## 2. 외부 서비스 사용

### 2-1. OCR (계좌번호 인식)
계좌번호 인식은 먼저 **기기 안에서** 처리합니다(iOS Vision, Android ML Kit). 이 단계에서는
이미지가 외부로 전송되지 않습니다.

기기 내 인식으로 계좌번호를 찾지 못했거나 결과의 신뢰도가 낮은 경우에만 Naver Cloud
Platform CLOVA OCR API에 이미지를 전송합니다. iOS와 Android 모두 동일합니다.

- 전송 대상: Naver Cloud Platform (한국)
- 전송 데이터: 사용자가 촬영하거나 선택한 이미지 (기기 내 인식에 실패한 경우에 한함)
- 보관 정책: 처리 즉시 폐기 (NCP CLOVA OCR 약관 기준)

### 2-2. 광고 (Kakao AdFit)
앱 내 배너 광고는 카카오 AdFit이 제공하며, 광고 노출을 위해 다음 정보가 카카오로
전송됩니다.

- **광고 식별자**
  - iOS: IDFA — 앱 추적 허용(ATT) 권한을 허용한 경우에 한함
  - Android: Google 광고 ID(AAID) — 광고 표시를 위해 사용되며, 사용자는 기기 설정에서
    광고 ID를 삭제하거나 개인 최적화를 해제할 수 있습니다
- 기기 정보 (OS 버전, 기기 모델 등)
- 광고 성과 측정용 데이터 (노출/클릭)

iOS에서 ATT 권한을 거부하거나 Android에서 광고 ID를 삭제·재설정해도 앱은 정상
동작하며, 비맞춤형 광고가 표시됩니다.

**광고 식별자 설정 변경 방법**

- iOS: 설정 > 개인정보 보호 및 보안 > 추적
- Android: 설정 > 개인정보 보호 > 광고 (기기 제조사에 따라 경로가 다를 수 있습니다)

광고 관련 자세한 처리 방침은 [카카오 AdFit 개인정보처리방침](https://www.kakao.com/policy/privacy)을 참고해주세요.

## 3. 권한 사용

### 공통
- **카메라**: 계좌 사진 촬영
- **클립보드**: 복사한 계좌번호 감지 (기기 내 처리, 위 1-1 참고)
- **네트워크**: OCR 요청 전송(기기 내 인식 실패 시) 및 광고 수신

### iOS
- **사진 보관함**: 기존 사진에서 계좌 추출
- **앱 추적(ATT)**: 맞춤형 광고 제공 (선택, 거부 가능)

### Android
- **광고 ID(AD_ID)**: 광고 표시 및 맞춤형 광고 제공

사진을 불러올 때는 시스템 사진 선택 도구를 사용하므로 저장소 접근 권한을 요청하지
않습니다.

## 4. 데이터 삭제

앱 삭제 시 모든 로컬 데이터가 함께 제거됩니다. 앱 내 계좌 목록에서 개별 계좌를 삭제하거나
전체를 비울 수도 있습니다.

광고 식별자는 앱이 아닌 기기 설정에서 관리되며, 위 2-2의 경로에서 삭제·재설정할 수 있습니다.
